LA ESQUINA BORRACHA FC — PROTOTIPO V1

Abrir index.html en un navegador para ver la página.
Incluye escudo original, 25 jugadores actuales, 19 exjugadores, palmarés, buscador, partidos y editor local.

IMPORTANTE:
- Es un prototipo local: no tiene autenticación ni base de datos compartida.
- Los cambios se guardan en localStorage del navegador y NO se sincronizan entre dispositivos.
- Usar Exportar datos JSON para conservar un respaldo.
- No introducir DNI, fechas de nacimiento ni datos privados.
- Estadísticas históricas incompletas se marcan como pendientes; no se inventan.

Para producción: migrar datos a Supabase, implementar autenticación real y permisos de administrador, y publicar en Vercel.
